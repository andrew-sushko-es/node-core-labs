# Lesson 01 — Runtime Inspector

**Этап:** Runtime fundamentals  
**Оценка времени:** 30–45 минут  
**Зависимости:** установленный Node.js; сторонние пакеты не нужны

## Цель

Научиться получать базовую информацию о Node.js runtime и текущем процессе через глобальный объект `process`.

После задания ты должен понимать, что версия Node.js, версия V8 и версия libuv — разные сведения, а текущая рабочая директория процесса не обязательно совпадает с директорией файла скрипта.

## Краткая справка

У объекта `process` есть свойства и методы для получения информации о запущенном процессе. Для этого упражнения пригодятся:

- `process.version`
- `process.versions.v8`
- `process.versions.uv`
- `process.platform`
- `process.arch`
- `process.pid`
- `process.cwd()`
- `process.argv`
- `process.execPath`

Документация: [Node.js Process](https://nodejs.org/api/process.html#process).

Пока не устанавливай сторонние пакеты и не используй готовые библиотеки для разбора аргументов командной строки.

## Задание

Создай файл `01-runtime/runtime-inspector.js`.

Напиши программу, которая выводит в консоль следующие сведения:

| Что вывести                      | Источник  |
| -------------------------------- | --------- |
| Версия Node.js                   | `process` |
| Версия V8                        | `process` |
| Версия libuv                     | `process` |
| Операционная система / платформа | `process` |
| Архитектура CPU                  | `process` |
| Process ID                       | `process` |
| Текущая рабочая директория       | `process` |
| Аргументы запуска                | `process` |
| Путь к исполняемому Node.js      | `process` |

Запусти программу с аргументами:

```bash
node 01-runtime/runtime-inspector.js --name Andrew --mode development
```

Формат вывода выбери самостоятельно: например, сгруппированный текст или объект с понятными названиями полей.

## Исследование поведения

После первого запуска:

1. Объясни, какие элементы содержит `process.argv` и почему это массив.
   Содержит массивб каждый элемент которого это часть команды. первый элемент путь к исполняемому nodeJS, дальше путь к запускаемому файлу, дальше идут параметры и их значения, все это отдельные элементы массива
2. Запусти скрипт из другой текущей директории, используя корректный относительный или абсолютный путь к файлу. Сравни `process.cwd()` и путь к скрипту.
   Они отличаются
3. Запусти две копии программы одновременно и сравни их PID.
   разные

## Критерии готовности

- [ ] Выведены все девять значений из таблицы.
- [ ] Программа запускается без сторонних зависимостей.
- [ ] Аргументы запуска отображаются полностью, включая пользовательские флаги и их значения.
- [ ] Ты можешь объяснить разницу между Node.js, V8 и libuv на базовом уровне.
- [ ] Ты можешь объяснить разницу между текущей рабочей директорией и расположением файла скрипта.

## Вопросы для самопроверки

1. Чем отличаются `process.version` и `process.versions.v8`?
   version - версия ноды, а versions.v8 - это версия движка
2. Где в `process.argv` находятся путь к исполняемому файлу Node.js, путь к скрипту и пользовательские аргументы?
   собственно как писал, что это все элементы массива argv
3. Что определяет `process.cwd()`?
   директорию из которой запускается скрипт
4. Почему у двух одновременно запущенных копий программы обычно разные PID?
   запускаются в отдельных процессах
5. Означает ли наличие нескольких версий компонентов в `process.versions`, что каждый из них является отдельным процессом?
   нет
